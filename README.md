## Entry

See `entry.txt` — the line `main.py` writes to `/output/entry.txt`.

## Run

```sh
python3 main.py  # writes /output/entry.txt
```

Python standard library only, no dependencies. Deterministic: running it twice produces byte-identical output (sha256 recorded in `TRANSCRIPT.md`).
